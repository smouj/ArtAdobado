# ArtAdobado app icon

Official Adobado product mark from the owner-supplied `Adobado_Icon_Pack_Final.zip`.

The PNG and ICO sources are copied byte-for-byte from the pack. The SVG packaging wrappers embed the official 512 px PNG, and the ICNS/hicolor images are size-appropriate renders of the official 1024 px PNG.
