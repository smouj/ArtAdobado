ArtAdobado portable mode

While this file sits next to vectorcraft.exe, ArtAdobado keeps its preferences, swatch and
graphic style libraries, added fonts, crash-recovery files and logs in the ArtAdobadoData folder
beside it, and writes nothing to %APPDATA%. Copy the whole folder to move ArtAdobado with its
settings. The first time ArtAdobadoData is created, any settings already in
%APPDATA%\ArtAdobado are copied into it; the originals are left where they were.

Keep this folder somewhere only you can write to: whoever can write here decides your settings,
including the plug-ins and fonts folders ArtAdobado loads from, and the Data Recovery copies of
your unsaved documents are kept here too.

Delete this file to use the normal per-user settings folder (%APPDATA%\ArtAdobado) instead.
If ArtAdobadoData can't be written (for example on a read-only drive), ArtAdobado logs a
warning and uses %APPDATA%\ArtAdobado instead.
